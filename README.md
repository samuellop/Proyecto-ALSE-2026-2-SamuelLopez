# Gestor de Inventario para Motocicletas 🏍️

Proyecto final para el curso **Algoritmos en Sistemas Electrónicos** (ALSE 2026-2).

**Estudiante:** Samuel López
**Docente:** Ing. Daniel Palomino Suarez MSc.

## Descripción
Aplicación de escritorio desarrollada en C++ con Qt para la gestión de inventario de repuestos y accesorios para motocicletas. Permite el control de stock, registro de movimientos, generación de alertas y exportación de reportes.

## Tecnologías
- **Lenguaje:** C++
- **Framework GUI:** Qt 6
- **Base de datos:** SQLite
- **Sistema de construcción:** CMake
- **Documentación:** Doxygen
